# Native target foundation

This directory reserves the Unity target and records the upstream editor version. It is not yet a runnable Unity project: no inherited scenes, models, XR settings with missing asset GUIDs, or teacher content have been copied.

Next native work: establish clean project settings and SDK configuration from the approved source/reference samples, implement the shared package importer, then validate a new client scene against WebXR. Do not open/build this folder as a completed player or claim device acceptance.
